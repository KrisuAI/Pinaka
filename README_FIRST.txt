QUICK START:
============

METHOD 1 - Git (Fastest):
   git clone https://github.com/KrisuAI/Pinaka.git
   cd Pinaka
   cp -r D:\Apps\SessionReplayTester\visual-test-builder\UPLOAD_TO_PUBLIC_REPO\* .
   git add .
   git commit -m "Add community templates"
   git push

METHOD 2 - Web Upload:
   1. Go to https://github.com/KrisuAI/Pinaka
   2. Upload all files/folders
   3. Done!

AFTER UPLOAD:
=============

1. Enable Discussions in repository settings
2. Create 5 discussion categories (see HOW_TO_SETUP.md)
3. Post welcome announcement
4. Done!
